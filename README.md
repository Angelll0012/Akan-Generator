 # Akan Name Generator
 -A web application that takes a user's birthday and gender as input, calculates the day of the week they were born, and determines their Ghanaian "Akan" name.

#  Features
-Form-Based Inputs: Easily enter day, month, year, and select a gender.
-Input Validation:Prevents empty inputs, non-numeric data, and invalid dates (e.g., days outside 1-31).
-Day-of-Week Calculation:Uses a Zeller's-like century formula to accurately determine the exact birth day.


# Technologies Used
-HTML: Semantic structure and form elements.
-CSS: Styling and layout layout (optional/custom).
-JavaScript DOM manipulation, form handling via `FormData`, and date logic computation.

# How to Run the Project
1. Download this repository to your local machine.
2. Ensure you have three essential files in the same folder:
   -index.html
   -style.css
   -script.js
3. Open `index.html` in any modern web browser (Chrome, Safari, Edge, Firefox).
4. Fill out the form fields and click Submit to see your Akan name.
